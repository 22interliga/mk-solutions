# MK Solutions — Last Mile

Sistema de apresentação e gestão operacional Last Mile da MK Solutions.

## Recursos
- Dashboard operacional
- Controle de piso
- Recebimento DS, triagem, despacho e rota
- SLA por período, motorista, base e localidade
- Cadastro de motoristas
- Gestão de despesas
- Usuários/Admin demonstrativos
- Importação CSV/XLS/XLSX
- Relatórios e exportações
- Assistente operacional demonstrativo

> Versão de apresentação: os dados são gravados no navegador local. Para produção multiusuário, conectar banco online e autenticação.
